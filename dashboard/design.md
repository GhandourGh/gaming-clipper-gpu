# Design — Gaming Clipper

A shared design system for the owner dashboard. Queue and job pages use the same atmospheric component language.

## Genre

Atmospheric creative tool: dark, tactile, direct, and legible for a non-technical owner.

## Macrostructure family

- Dashboard: spacious overview with three summary panels and large recent-job rows.
- New job: guided three-step form on a dedicated route.
- Job pages: Bento Grid with a linear pipeline inside one wide panel.

## Theme

- Canvas: near-black violet.
- Surfaces: three solid elevation levels; no glass panels.
- Signal accent: violet supported by electric blue.
- Status colours remain semantic and are never the only status signal.

## Typography

- Display: Space Grotesk, weight 600–700, tight tracking, roman.
- Body: Inter, weight 400–600.
- Technical labels and costs: system monospace.

## Motion

- Informational motion only: processing orbit, letter pulse, subtle hover lift.
- No layout-changing animation.
- Reduced motion collapses animation to near-instant state changes.

## Component voice

- Floating pill navigation.
- Rounded solid panels with restrained inset highlights.
- Primary actions use the violet signal colour and soft hover glow.
- Upload is a dashed drop surface; generation gets an explicit animated state.
- Controls retain visible labels, keyboard focus, disabled state, and 44px minimum targets.

## What pages must share

The token palette, button geometry, panel radii, focus treatment, navigation, status vocabulary, and motion limits.
